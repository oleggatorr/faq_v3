# Модели данных

## Назначение раздела

Раздел описывает сущности БД, поля, связи и правила использования в бизнес-логике тикетной системы.

## Основные сущности

- `Agent` - сотрудники, работающие с тикетами.
- `Ticket` - обращение пользователя.
- `Message` - сообщение в рамках тикета.
- `Attachment` - файл, прикрепленный к сообщению.
- `TicketEvent` - событие/аудит изменений по тикету.
- `Department` - отдел обработки.
- `QuestionCategory` - категория обращения.
- `TicketStatus` - статус тикета.
- `Language` - язык обращения.

## Связи верхнего уровня

- Один `Ticket` содержит много `Message`.
- Один `Message` содержит много `Attachment`.
- Один `Ticket` содержит много `TicketEvent`.
- `Ticket` ссылается на `Department`, `QuestionCategory`, `TicketStatus`, `Language`.
- `Agent` может быть владельцем и исполнителем действий по тикету.
