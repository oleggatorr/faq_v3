# Документация проекта

## О проекте

Бэкенд-система для приема жалоб и предложений в формате тикетов.
Пользователь создает обращение без регистрации, получает `track_id` и ведет диалог с оператором по этому трек-номеру.

## Что важно в текущей версии

- Пользователь не регистрируется.
- Тикет создается с первым сообщением и может содержать вложения.
- Операторы работают в интерфейсе обработки тикетов.
- Для оператора задаются:
  - доступ к категориям (`category_access`)
  - набор действий/прав (`permissions`)
